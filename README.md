# team-task-tracker

Семинарское задание по НИС «Промышленная веб-разработка на React»: участники команды и их задачи.

## Запуск

Нужен Node.js 22.12+. В двух терминалах из корня проекта:

```bash
# API — http://localhost:3001
cd api
npm ci
npm start
```

```bash
# UI — http://localhost:5173
npm ci
npm run dev
```

```bash
npm run build
npm run typecheck
npm run lint
npm run preview
```
